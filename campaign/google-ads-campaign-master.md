# CONVERSION TRACKING SETUP

## Step 1 — Google Tag Installation

1. Go to Google Ads → **Tools → Conversions → New Conversion**
2. Select **Website**
3. Name: `Bridge Page View`
4. Category: Page view
5. Value: (leave blank or set to $1 — proxy metric)
6. Count: Every

Copy the **Global Site Tag (gtag.js)** and paste it into `<head>` of `healthreport.today` page.

**OR** — add this snippet alongside the existing Meta Pixel (already in the page):

```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=AW-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'AW-XXXXXXXXXX');
</script>
```

Replace `AW-XXXXXXXXXX` with your Google Ads Conversion ID.

## Step 2 — Conversion Actions to Create

| Conversion Name | Trigger | Value | Count |
|---|---|---|---|
| `Bridge_PageView` | Page visit | $0 | Once |
| `Bridge_ScrollDepth75` | scroll event depth_75 | $0.50 | Once |
| `Bridge_CTAClick` | Button click (BridgeClick) | $1 | Once |
| `Purchase_ClickBank` | Import from ClickMagick via GCLID | $143 | Once |

## Step 3 — Import Purchase Conversions via ClickMagick

ClickMagick can send conversions to Google Ads via GCLID passthrough:

1. In your ClickMagick tracking link, enable **Google Click ID (GCLID) passthrough**
2. Add `gclid={gclid}` to your destination URL: `https://healthreport.today?gclid={gclid}`
3. In ClickMagick → Settings → Conversion Tracking → Google Ads:
   - Conversion ID: `AW-XXXXXXXXXX`
   - Conversion Label: (from your Google Ads conversion action)
4. When ClickBank fires the IPN → ClickMagick fires the Google Ads conversion tag
5. Google Ads registers the Purchase

## Step 4 — URL Parameter Setup

Add to all ad final URLs:
```
?utm_source=google&utm_medium=cpc&utm_campaign=[campaign]&utm_content=[adgroup]&gclid={gclid}
```

Google auto-populates `{gclid}`. Do NOT encode it. Pass it through ClickMagick to ClickBank IPN.

# QUALITY SCORE OPTIMIZATION

Quality Score affects your ad position and CPC. High QS = better position at lower cost.

## The QS Triangle

```
Expected CTR + Ad Relevance + Landing Page Experience = Quality Score (1-10)
```

## What to do for each factor:

### Expected CTR (target: Above Average)
- Use the exact keyword IN the headline (Google bolds it — increases CTR)
- Add numbers: "34 lbs", "8 ingredients", "3 minutes"
- Add emotion words: "finally", "discover", "secret", "real reason"
- Test ad copy — pause lowest CTR ads after 200 impressions

### Ad Relevance (target: Above Average)
- Create tight ad groups — max 10 keywords per group
- Each keyword theme gets its OWN ad
- Headline 1 must contain the core keyword phrase
- Use Dynamic Keyword Insertion {KeyWord:Default} in Headline 2

### Landing Page Experience (target: Above Average)
- Page must load in under 3 seconds (critical for QS)
- Page content must match the ad keywords
- "Ceramide" and "metabolism" must appear in the page text
- Page must have a clear CTA above the fold
- Mobile-optimized (test on mobile before launching)
- NO redirect chains — ad → healthreport.today directly

**Test Page Speed:**
- Google PageSpeed Insights: pagespeed.web.dev
- Target: Mobile score ≥ 70, Desktop ≥ 90
