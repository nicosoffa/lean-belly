**Asset naming convention:**
```
[angle]-[type]-[size]-[version].ext
Examples:
mito-img-1080x1080-v1.jpg
fam-vid-9x16-v1.mp4
mito-vid-1x1-v2.mp4
```

**Image specs:**
- Format: JPG or PNG (JPG preferred for photos, PNG for graphics with text)
- Max file size: 1MB per image
- No logo overlay required (bridge page acts as brand)
- Text on image: max 20% of image area (Meta rule)
- Must work WITHOUT reading the text (visual should tell the story alone)

**Video specs:**
- Format: MP4 (H.264)
- Aspect ratios: 9:16 (primary for Reels/Stories) + 1:1 (Feed)
- Resolution: 1080p minimum
- Max file size: 4GB (keep under 500MB for fast upload)
- Audio: include, but hook must work on mute (first 3s must communicate visually)
- Captions: hardcoded or SRT file
